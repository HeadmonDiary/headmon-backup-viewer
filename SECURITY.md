# Security policy

Headmon backups can contain sensitive health information. Report suspected
security or privacy vulnerabilities privately by emailing
**headmon@proton.me** with a concise description, the affected revision or
page, and safe reproduction steps.

Do not include a real backup, export, medical record, diary entry, private
photo, precise location, access token, or other personal information. Use
minimal invented data when a sample is necessary. Messages containing personal
information may be deleted without a response.

Please do not open a public issue for a vulnerability before it has been
investigated and a coordinated disclosure date has been agreed. You can expect
an acknowledgement within seven days. The project does not currently offer a
bug bounty or authorize access to other people's data or systems.
